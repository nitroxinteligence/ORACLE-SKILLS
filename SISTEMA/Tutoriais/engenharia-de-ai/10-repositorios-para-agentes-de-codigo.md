# 10 repositórios para deixar agentes de código mais poderosos

Este tutorial reúne os dez repositórios apresentados por [Leonard Rodman](https://x.com/RodmanAi/status/2098340192499413240) para ampliar o uso de agentes de código como Claude Code, Codex, Cursor e OpenCode.

## 1. gstack

Transforma seu agente de código em uma equipe completa de engenharia.

Inclui fluxos voltados a planejamento, desenvolvimento, revisão, QA, segurança e entrega de software.

**Repositório:** [garrytan/gstack](https://github.com/garrytan/gstack)

## 2. context-mode

Reduz saídas desnecessárias de ferramentas e melhora o gerenciamento do contexto usado pelo agente.

É útil para sessões longas e tarefas que produzem muitas respostas de terminal, arquivos ou ferramentas externas.

**Repositório:** [mksglu/context-mode](https://github.com/mksglu/context-mode)

## 3. OpenCode

Agente de código open source executado diretamente no terminal.

Permite trabalhar com código, arquivos, comandos e modelos a partir de uma interface própria de linha de comando.

**Repositório:** [opencode-ai/opencode](https://github.com/opencode-ai/opencode)

## 4. Superpowers

Adiciona um fluxo estruturado para planejar, programar, depurar e revisar software.

Organiza o trabalho do agente em etapas reutilizáveis para tarefas de engenharia.

**Repositório:** [obra/superpowers](https://github.com/obra/superpowers)

## 5. Learn Claude Code

Ensina como agentes de código funcionam por meio da construção de um agente desde o início.

O conteúdo cobre a criação do harness, ferramentas, memória, contexto, subagentes, permissões, hooks e MCP.

**Repositório:** [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)

## 6. Ruflo

Coordena vários agentes, ferramentas, memórias e fluxos de trabalho.

Funciona como uma camada de orquestração para organizar equipes de agentes e processos mais extensos.

**Repositório:** [ruvnet/ruflo](https://github.com/ruvnet/ruflo)

## 7. OpenCode Agents

Oferece agentes especializados prontos para diferentes fluxos de programação.

Os agentes podem assumir funções específicas durante planejamento, implementação, testes e revisão.

**Repositório:** [remcocats/opencode-agents](https://github.com/remcocats/opencode-agents)

## 8. Agent Skills

Reúne skills reutilizáveis que fornecem capacidades especializadas a agentes de código.

As skills cobrem diferentes áreas do desenvolvimento e podem ser incorporadas ao fluxo do agente conforme a tarefa.

**Repositório:** [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)

## 9. Paseo

Permite orquestrar vários agentes de código dentro de um único fluxo de trabalho.

Centraliza a criação, o acompanhamento e a coordenação de sessões executadas por diferentes agentes.

**Repositório:** [getpaseo/paseo](https://github.com/getpaseo/paseo)

## 10. MCP Servers

Conecta agentes de IA a bancos de dados, APIs, navegadores, GitHub e outras ferramentas externas por meio do Model Context Protocol.

O repositório reúne servidores MCP e referências para ampliar as ferramentas disponíveis ao agente.

**Repositório:** [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)

## Como usar a lista

1. escolha o repositório relacionado à capacidade que você deseja adicionar;
2. abra o link do projeto no GitHub;
3. siga o procedimento de instalação descrito no próprio repositório;
4. conecte ou invoque a ferramenta no agente de código compatível;
5. use a nova capacidade no seu fluxo de desenvolvimento.

Os dez projetos foram apresentados na publicação como recursos open source para aproveitar melhor Claude Code, Codex, Cursor e OpenCode.
